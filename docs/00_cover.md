\## ABSTRATU



Projetu Capstone ida-ne'e dezenvolve sistema análize streaming merkadu saham real-time ba kompañia minarai no gás ne'ebé operasaun iha Timor-Leste. Sistema uza arquitetura Big Data pipeline ne'ebé konsiste husi: yfinance API hanesan fonte dadus, Apache Kafka hanesan data ingestion, Apache Spark Streaming hanesan stream processing, PostgreSQL hanesan data storage, no Streamlit hanesan visualization dashboard.



Objetivu prinsipal husi projetu ida-ne'e mak atu aplika teoria no pratika Big Data iha problema real, liu-liu atu monitoriza movimentu saham kompañia sira ne'ebé iha ligasaun direita ho ekonomia Timor-Leste. Saham sira ne'ebé analiza mak: Santos Ltd (STO.AX), Woodside Energy (WDS.AX), no Finder Energy (FDR.AX) — kompañia sira ne'ebé opera iha setor minarai no gás iha Timor-Leste.



Sistema ne'ebé dezenvolve bele prosesa dadus streaming husi API, transforma no agrega dadus iha window tempu 1 minutu, kalkula indikador analitiku hanesan Moving Average (MA-5, MA-20), volatility, no deteksaun trend, no aprezenta rezultadu iha dashboard interaktivu.



\*\*Rezultadu:\*\* Sistema susesu prosesa liu husi 1.450 rekorde dadus, ho agregasaun window 1 minutu ne'ebé kontinua atualiza, no dashboard ne'ebé bele visualiza dadus real-time.
